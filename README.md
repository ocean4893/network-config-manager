system-view

支持运算：`{字段名+10}`、`{字段名-5}`、`{字段名*2}`、`{字段名/3}`

---

## 📁 数据文件格式

- 支持 `.xlsx`、`.xls` 和 `.csv` 格式
- **无表头**，数据从指定行开始读取
- 需在软件中自定义 **字段列**（字段名 → Excel 列字母映射）

### 示例 Excel 结构（配置生成）

| A | B | C | D |
|---|---|---|---|
| ... | 100 | 10.1.1.1/24 | ... |
| ... | 200 | 10.2.2.1/24 | ... |

设置字段：`vlan_number` → B, `ip_address` → C

### 下发功能必备字段

下发 Excel 必须包含以下三个字段（列字母可自定义）：
- **host_ip** – 设备 IP 地址
- **user_name** – SSH 用户名
- **user_password** – SSH 密码

## 📖 使用说明

### 1. 配置批量生成

1. 点击主菜单 **配置批量生成**
2. **加载 excel 文件**：选择数据源
3. **执行字段列**：定义字段名与 Excel 列字母的对应关系，设置开始行
4. **配置生成模板**：编写包含 `{字段名}` 的配置模板
5. **开始生成** → 使用 **上一个** / **下一个** 浏览生成结果
6. **复制** 按钮可将当前配置复制到剪贴板

### 2. 配置批量生成下发

1. 点击主菜单 **配置批量生成下发**
2. 加载包含 IP、用户名、密码的 Excel
3. 执行字段列（必须包含 `host_ip`、`user_name`、`user_password`）
4. 编辑配置模板（同样支持 `{字段}` 语法）
5. 设置线程数量、是否开启保存检测
6. **开始下发** → 右侧窗口实时显示正在处理的设备
7. 完成后查看日志文件（`deploy_runtime.log`、`deploy_success.txt`、`deploy_failure.txt`）
